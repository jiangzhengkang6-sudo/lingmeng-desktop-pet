# 智能体声纹配置与验收指南

本文档对应当前项目中的 Volcengine RTC 声纹身份链路。它说明如何准备云端配置、注册主人声纹、启动 RTC 任务、接收官方回调、提交本地身份网关，以及如何区分“代码测试通过”和“官方客户端实测通过”。

## 1. 结论先看

当前项目的声纹链路已经完成了本地安全边界和 RTC OpenAPI 控制层：

- 服务端可以通过 `RegisterVoicePrint` 注册一个 WAV 样本。
- 注册成功后，只把返回的 `VoicePrintId` 写入本地 RTC 场景文件。
- 服务端可以通过 `StartVoiceChat` 和 `StopVoiceChat` 控制一个身份验证用途的 RTC 任务。
- 官方 RTS HTTP 回调先完成共享密钥校验，再解包 `subv` 二进制字幕。
- 身份网关只接受当前唯一活动 RTC 任务中、目标真人用户的完整句；本地 HMAC 事件桥仍保留给离线脱敏样本。
- 声纹名称匹配且分数达到阈值时，身份状态才变成 `owner_verified`。
- 主人身份只决定隐私记忆和受控工具权限，不会绕过工具审批。

仍需要官方 RTC 客户端或官方 SDK 加入真实房间，产生真实识别结果，才能完成最终端到端验收。脱敏 JSON、单元测试和本地签名测试不能代替这一步。

## 2. 链路架构

```text
主人 WAV
  │
  ├─ POST /api/identity/rtc/voiceprints/register
  │       │
  │       └─ 服务端调用 RegisterVoicePrint
  │               └─ 返回 VoicePrintId
  │                       └─ 写入 voiceprint-rtc-scene.json
  │
  └─ 官方 RTC 客户端/SDK 加入真实房间
          │
          └─ StartVoiceChat 创建的 TaskId
                  │
                  └─ 火山 RTS HTTP 回调（message + signature）
                  │
                  └─ /api/identity/rtc/rts/messages
                          │
                          ├─ Base64 解码 subv/stat 二进制
                          ├─ stat 仅记录功能状态，不授权
                          └─ 完整真人 subv 字幕
                                  │
                                  └─ owner_verified 或 guest
```

这条链路和豆包 SAUC ASR 是两条独立链路：

- SAUC 负责把语音转换成文字。
- RTC VoiceChat 声纹配置负责识别说话人。
- ASR 的文本、`log_id` 或其他响应不能直接当作声纹认证结果。

## 3. 配置前的安全要求

### 3.1 密钥只能放在服务端

以下配置只能写入项目根目录的服务端 `.env`，不能写入前端 `.env.frontend`、Vue 代码、Godot 资源、安装包或提交到 Git：

- `VOICEPRINT_RTC_ACCESS_KEY_ID`
- `VOICEPRINT_RTC_SECRET_ACCESS_KEY`
- `VOICEPRINT_RTC_BRIDGE_SECRET`
- `VOICEPRINT_RTC_CALLBACK_SECRET`
- 其他云厂商 API Key、App Key、Secret、签名材料

前端只调用本地网关，例如 `http://127.0.0.1:8000`。本地网关再使用服务端密钥调用 RTC OpenAPI。

### 3.2 不要把回调样本当成密钥

官方脱敏回调可以用于字段结构检查，但不能包含：

- AK、SK、API Key、AppId 的完整敏感值；
- Authorization、签名、Cookie；
- 原始录音；
- 不必要的完整转写文本；
- 可以直接复用的生产任务号。

回调中的 `TaskId` 必须来自当前本地启动的 RTC 会话，不能从脱敏样本复制。

## 4. Volcengine 控制台准备

在 Volcengine 控制台完成以下准备：

1. 开通 RTC AI 音视频交互或对应 VoiceChat 能力。
2. 创建或确认 RTC 应用，得到 `APP_ID`。
3. 创建具有 RTC OpenAPI 最小权限的访问凭据，得到 `ACCESS_KEY_ID` 和 `SECRET_ACCESS_KEY`。
4. 在 RTC 智能体配置中启用声纹能力，并准备 `RegisterVoicePrint` 所需的音频样本。
5. 确认智能体使用的 ASR 配置与项目约定一致。当前场景写入 `StreamMode: 0`，这是单向流式配置。
6. 准备一个公网可访问的 HTTPS 回调地址。本地开发可使用 Cloudflare Quick Tunnel 临时映射到 `http://127.0.0.1:8000`。

如果控制台要求申请白名单、开通权限或提交工单，应先完成云侧开通。代码侧的配置检查不会绕过云平台权限。

## 5. 服务端 `.env` 配置

下面是配置模板。真实值只填入项目根目录的 `.env`，不要把真实值写回本文档：

```env
VOICEPRINT_PROVIDER=volcengine-rtc
VOICEPRINT_RTC_OWNER_NAME=desktop-owner
VOICEPRINT_RTC_SCORE_THRESHOLD=50
VOICEPRINT_RTC_BRIDGE_SECRET=<本地 HMAC 随机高熵字符串>
VOICEPRINT_RTC_CALLBACK_URL=https://<公网域名>/api/identity/rtc/rts/messages
VOICEPRINT_RTC_CALLBACK_SECRET=<RTS 回调独立随机高熵字符串>

VOICEPRINT_RTC_ACCESS_KEY_ID=<RTC_ACCESS_KEY_ID>
VOICEPRINT_RTC_SECRET_ACCESS_KEY=<RTC_SECRET_ACCESS_KEY>
VOICEPRINT_RTC_APP_ID=<RTC_APP_ID>
VOICEPRINT_RTC_REGION=cn-north-1
VOICEPRINT_RTC_API_VERSION=2025-06-01
VOICEPRINT_RTC_SCENE_PATH=backend/config/voiceprint-rtc-scene.json
VOICEPRINT_RTC_TIMEOUT_SECONDS=15
VOICEPRINT_RTC_SESSION_TTL_SECONDS=3600
```

字段说明：

| 字段 | 用途 | 注意 |
| --- | --- | --- |
| `VOICEPRINT_PROVIDER` | 选择身份适配器 | 真实 RTC 使用 `volcengine-rtc` |
| `VOICEPRINT_RTC_OWNER_NAME` | 注册音频名称，也是回调匹配名称 | 必须和 `AudioName`、官方 `voiceprintName` 完全一致 |
| `VOICEPRINT_RTC_SCORE_THRESHOLD` | 本地放行阈值 | 当前分数范围为 `1` 到 `100`，建议先用 `50`，再根据实测调整 |
| `VOICEPRINT_RTC_BRIDGE_SECRET` | 本地可信 worker 到本地网关的 HMAC 密钥 | 与云端 AK/SK、RTS 回调密钥不同，不能复用 |
| `VOICEPRINT_RTC_CALLBACK_URL` | 火山 RTS 服务端回调地址 | 必须是公网 HTTPS，路径为 `/api/identity/rtc/rts/messages` |
| `VOICEPRINT_RTC_CALLBACK_SECRET` | 官方 RTS 外层 `signature` 校验密钥 | 每次启动会话时传给 `ServerMessageSignatureForRTS`，不能写入场景 JSON |
| `VOICEPRINT_RTC_ACCESS_KEY_ID` | 服务端调用 RTC OpenAPI 的访问 ID | 只在后端使用 |
| `VOICEPRINT_RTC_SECRET_ACCESS_KEY` | 服务端调用 RTC OpenAPI 的签名密钥 | 只在后端使用 |
| `VOICEPRINT_RTC_APP_ID` | RTC 应用 ID | 不是 `VOICEPRINT_RTC_OWNER_NAME` |
| `VOICEPRINT_RTC_API_VERSION` | RTC OpenAPI 版本 | 当前项目默认 `2025-06-01` |
| `VOICEPRINT_RTC_SCENE_PATH` | 场景 JSON 路径 | 注册后会写入声纹 ID |
| `VOICEPRINT_RTC_SESSION_TTL_SECONDS` | 本地允许回调的任务生命周期 | 停止、重启、过期后旧任务都会失效 |

`VOICEPRINT_RTC_OWNER_NAME` 可以使用 `desktop-owner` 这样的稳定标识，不要求是真人姓名。关键是注册时、场景识别时和回调映射时必须使用同一个字符串。


### 5.1 Cloudflare Quick Tunnel（本地验收）

本地开发时先启动只放行 RTS 路径的反向代理，再使用项目内便携版 `tools/cloudflared.exe`。Quick Tunnel 不需要系统安装或登录：

```powershell
python scripts\rts_public_proxy.py --listen-host 127.0.0.1 --port 8001
tools\cloudflared.exe tunnel --url http://127.0.0.1:8001 --no-autoupdate
```

公网只能访问 `/api/identity/rtc/rts/messages`；通过隧道访问其他本地接口会返回 404。

启动后从输出中复制 `https://<随机域名>.trycloudflare.com`，并拼接固定路径：

```text
https://<随机域名>.trycloudflare.com/api/identity/rtc/rts/messages
```

然后使用该地址启动或重启本地 FastAPI：

```powershell
$env:VOICEPRINT_RTC_CALLBACK_URL="https://<随机域名>.trycloudflare.com/api/identity/rtc/rts/messages"
$env:VOICEPRINT_RTC_CALLBACK_SECRET="<本次验收专用随机密钥>"
python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000
```

隧道仅在当前验收期间运行，结束后停止进程即可。不要把临时回调密钥写入前端配置或场景文件。

## 6. RTC 场景文件

项目使用：

```text
backend/config/voiceprint-rtc-scene.json
```

示例结构：

```json
{
  "AgentConfig": {
    "VoicePrint": {
      "Mode": 2,
      "IdList": [
        "<RegisterVoicePrint 返回的 VoicePrintId>"
      ],
      "Score": 50.0
    },
    "EnableConversationStateCallback": true
  },
  "Config": {
    "ASRConfig": {
      "ProviderParams": {
        "StreamMode": 0
      }
    }
  }
}
```

场景文件不能覆盖运行时字段：

- 顶层 `AppId`
- 顶层 `RoomId`
- 顶层 `TaskId`
- `AgentConfig.UserId`
- `AgentConfig.TargetUserId`

这些字段由本地 API 请求在每次启动任务时注入。不要手工把它们写进场景文件。

`Mode: 2` 表示使用预注册声纹 ID 列表，`IdList` 中放云端注册返回的 ID，`Score` 是云端配置和本地放行判断使用的起始阈值。注册接口成功后，后端会自动更新这些字段，并强制保持 `StreamMode: 0` 和会话状态回调开启。

## 7. WAV 录制要求

声纹注册接口只接受以下 WAV：

- PCM、未压缩；
- 16 kHz；
- 16-bit；
- 单声道；
- 15 到 30 秒；
- 文件大小不超过 1.5 MB。

录音建议：

- 使用安静环境，避免音乐、风声和多人说话；
- 让主人连续自然说话，不要只录一个短词；
- 录音开头和结尾不要有明显爆音；
- 不要把录音保存进 Git；
- 注册完成后，本地后端不会把原始音频写入数据库或场景文件。

注册接口：

```text
POST /api/identity/rtc/voiceprints/register
Content-Type: multipart/form-data

audio=<owner.wav>
confirmed=true
```

PowerShell 示例：

```powershell
curl.exe -X POST http://127.0.0.1:8000/api/identity/rtc/voiceprints/register `
  -F "audio=@C:\path\owner.wav;type=audio/wav" `
  -F "confirmed=true"
```

成功响应只应包含声纹 ID、音频名称、算法版本、场景是否更新和请求号，例如：

```json
{
  "voiceprintId": "provider-generated-id",
  "audioName": "desktop-owner",
  "algorithmVersion": 2,
  "sceneUpdated": true,
  "requestId": "provider-request-id"
}
```

该接口会触发真实云端写入，因此必须由主人明确确认后再调用。

## 8. 调取 RTC 会话

### 8.1 启动

```text
POST /api/identity/rtc/sessions
Content-Type: application/json
```

请求：

```json
{
  "roomId": "desktop-pet-identity",
  "agentUserId": "desktop-pet-agent",
  "targetUserIds": [
    "desktop-owner"
  ],
  "purpose": "identity_verification",
  "confirmed": true
}
```

响应中最重要的是本地保存的真实 `taskId`：

```json
{
  "taskId": "provider-task-id",
  "appId": "provider-app-id",
  "roomId": "desktop-pet-identity",
  "requestId": "provider-request-id"
}
```

只有服务端通过 `StartVoiceChat` 成功拿到的 `taskId` 才能进入活动会话表。前端不能自行创建或猜测任务号。

### 8.2 停止

```text
DELETE /api/identity/rtc/sessions/{taskId}
```

停止成功后，本地立即删除活动任务。即使云端停止响应稍后才返回，本地也不会再接受该任务的旧回调。

## 9. 官方 RTS 回调接收

当前项目的真实 live 链路直接接收火山 RTS 服务端 HTTP 回调，不再要求官方客户端把事件手工写入 JSONL 文件。

### 9.1 StartVoiceChat 运行时配置

启动会话时，本地后端会在 `AgentConfig` 中注入：

- `ServerMessageURLForRTS`：公网 HTTPS 回调地址；
- `ServerMessageSignatureForRTS`：本次 RTS 回调共享密钥；
- `EnableConversationStateCallback=true`。

同时会确保 `Config.SubtitleConfig.SubtitleMode=0`。这些运行时字段不会写入 `backend/config/voiceprint-rtc-scene.json`，避免把回调密钥持久化到场景文件。

### 9.2 外层 HTTP 信封

云端向以下地址发起 POST：

```text
/api/identity/rtc/rts/messages
```

请求体外层包含：

```json
{
  "message": "Base64 编码的二进制消息",
  "signature": "StartVoiceChat 中配置的共享密钥"
}
```

本地网关先执行固定时间签名比较，再进行 Base64 解码。签名错误返回：

```text
401 RTC_RTS_SIGNATURE_INVALID
```

同一个路径也支持 GET，用于云端配置回调地址时的连通性检查。

### 9.3 `subv` 与 `stat` 二进制消息

二进制头固定为 8 字节：

```text
4 字节 magic + 4 字节大端长度 + UTF-8 JSON
```

| magic | 含义 | 是否能授予主人身份 |
| --- | --- | --- |
| `subv` | 实时字幕/对话记录 | 只有满足完整条件的真人字幕可以 |
| `stat` | 声纹功能状态：Disabled / Registering / Active / Failed | 不可以，只能说明功能状态 |

解包后的 `subv` JSON 示例：

```json
{
  "type": "subtitle",
  "data": [
    {
      "userId": "desktop-owner",
      "voiceprintId": "<云端声纹 ID>",
      "voiceprintName": "desktop-owner",
      "voiceprintScore": 52,
      "definite": true,
      "paragraph": true
    }
  ]
}
```

本地身份网关只接受同时满足以下条件的记录：

1. 当前本地服务中恰好有一个活动 RTC 任务；
2. `userId` 属于本次 `StartVoiceChat` 的 `TargetUserId`；
3. `definite=true` 且 `paragraph=true`，即真人完整句；
4. 声纹名称和分数字段完整；
5. 名称等于服务端配置的主人名；
6. 分数达到 `VOICEPRINT_RTC_SCORE_THRESHOLD`。

AI 字幕、半句、其他用户、多个目标完整句和格式不完整的事件都不能授权。完整真人句没有声纹匹配字段时，会进入未匹配/访客路径，避免保留旧主人权限。

接口响应和日志不包含原始字幕文本、完整声纹 ID、回调密钥或 AK/SK。

### 9.4 离线脱敏 JSON/JSONL Worker

以下 Worker 仍可用于离线检查“已解包后的 subtitle JSON”，但它不是官方 live 回调链路，不能替代真实 RTS 验收：

```powershell
python scripts/rtc_event_bridge_worker.py `
  --provider volcengine-rtc `
  --task-id "<本地启动会话返回的真实 TaskId>" `
  --input-file ".\rtc-callbacks-redacted.jsonl"
```

Worker 继续使用本地 `VOICEPRINT_RTC_BRIDGE_SECRET` 对标准化事件做 HMAC 签名；该密钥与官方 RTS 的 `VOICEPRINT_RTC_CALLBACK_SECRET` 职责不同，不能混用。

## 10. HMAC 事件桥安全机制

标准化内部事件：

```json
{
  "task_id": "provider-task-id",
  "voiceprint_name": "desktop-owner",
  "voiceprint_score": 52
}
```

签名原文：

```text
timestamp + "." + raw_compact_json_body
```

签名算法：

```text
hex(HMAC-SHA256(VOICEPRINT_RTC_BRIDGE_SECRET, 签名原文))
```

请求头：

```text
X-Desktop-Pet-Voiceprint-Timestamp: <Unix 秒>
X-Desktop-Pet-Voiceprint-Signature: <hex HMAC-SHA256>
Content-Type: application/json
```

网关检查：

- 桥接密钥已配置；
- 时间戳可解析；
- 时间戳与当前时间差不超过 `VOICEPRINT_RTC_CLOCK_SKEW_SECONDS`；
- HMAC 与原始请求体完全匹配；
- JSON 只有标准化字段；
- `TaskId` 仍是当前活动会话；
- 名称和分数通过本地声纹适配器判断。

## 11. 身份和权限判定

| 条件 | 身份状态 | 私有记忆 | 受控工具 |
| --- | --- | --- | --- |
| 未验证 | `unknown` | 禁止 | 禁止 |
| 名称不匹配 | `guest` | 禁止 | 禁止 |
| 分数低于阈值 | `guest` | 禁止 | 禁止 |
| 名称匹配且分数达到阈值 | `owner_verified` | 允许 | 允许，但仍需审批 |
| 任务已停止 | 不接受旧回调 | 不因旧回调恢复 | 不因旧回调恢复 |
| 任务已过 TTL | 不接受旧回调 | 不因旧回调恢复 | 不因旧回调恢复 |

主人认证不会直接执行桌面操作。打开文件、启动应用等中风险操作仍需要调试界面中的审批流程。

## 12. 验收脚本

脚本位置：

```text
scripts/verify_rtc_voiceprint_e2e.py
```

### 12.1 配置检查

只检查服务端配置、场景文件和本地网关状态，不调用云端注册或启动接口：

```powershell
python scripts/verify_rtc_voiceprint_e2e.py --mode config
```

输出只包含布尔配置状态、阈值、API 版本、场景字段摘要和网关状态，不打印 AK、SK、API Key、桥接密钥或声纹 ID。

通过条件：

- `VOICEPRINT_PROVIDER=volcengine-rtc`；
- 身份桥配置完整；
- RTC OpenAPI 配置完整；
- 场景 JSON 存在且合法；
- 场景中存在预注册声纹；
- 本地网关可访问；
- 网关报告 `identityBridgeConfigured=true`；
- 已配置公网 HTTPS RTS 回调地址和独立回调密钥；
- 网关报告 `callbackConfigured=true`、`liveConfigured=true`。

### 12.2 离线回调映射检查

离线模式只解析官方脱敏 JSON/JSONL，不调用身份网关，不改变主人身份：

```powershell
python scripts/verify_rtc_voiceprint_e2e.py `
  --mode offline `
  --input-file ".\rtc-callbacks-redacted.jsonl"
```

如果希望样本中必须包含至少一个可映射结果：

```powershell
python scripts/verify_rtc_voiceprint_e2e.py `
  --mode offline `
  --expect-match `
  --input-file ".\rtc-callbacks-redacted.jsonl"
```

离线模式支持：

- 单个 JSON 对象；
- JSON 数组；
- JSONL。

它会报告每条记录是状态事件、未匹配、可映射还是格式错误，并明确输出 `submitted: false`。

### 12.3 真实端到端验收

先启动 FastAPI，并在同一终端注入公网回调地址与本次临时 RTS 密钥：

```powershell
$env:VOICEPRINT_RTC_CALLBACK_URL="https://<随机域名>.trycloudflare.com/api/identity/rtc/rts/messages"
$env:VOICEPRINT_RTC_CALLBACK_SECRET="<本次验收专用随机密钥>"
python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000
```

先执行配置检查：

```powershell
python scripts/verify_rtc_voiceprint_e2e.py --mode config
```

确认通过后，执行真实 live 验收：

```powershell
python scripts/verify_rtc_voiceprint_e2e.py `
  --mode live `
  --live `
  --wait-seconds 300 `
  --room-id "desktop-pet-identity" `
  --agent-user-id "desktop-pet-agent" `
  --target-user-id "desktop-owner"
```

脚本流程：

1. 检查本地网关、官方 RTS 回调和 RTC OpenAPI 是否全部就绪；
2. 启动真实 RTC VoiceChat 会话并取得 `TaskId`；
3. 等待官方客户端/SDK 入房并由主人真实说话；
4. 火山云端直接把 RTS HTTP 回调投递到本地网关；
5. 本地网关解包 `subv` 并更新 `owner_verified` 或 `guest`；
6. 轮询 `/api/identity`，确认主人态；
7. 调用 `StopVoiceChat`；
8. 用本地 HMAC 标准化事件重放一次，检查旧回调返回 `HTTP 409` 与 `RTC_SESSION_NOT_ACTIVE`；
9. 无论成功或失败，尽量停止仍在运行的会话。

`--callback-file` 已废弃，仅为兼容旧命令保留；live 模式不再读取或等待本地 JSONL 文件。

这一步不能用脱敏样本代替。必须由官方客户端或 SDK 真实加入房间、产生音频，并由火山云端投递真实 RTS 回调。

如果希望验收后恢复本地身份状态，可以追加 `--reset-identity-after`。

### 12.4 最终验收清单

| 验收项 | 预期 |
| --- | --- |
| 配置检查 | 返回码 `0`，网关和场景均就绪 |
| 注册 WAV | 返回 `voiceprintId`，`sceneUpdated=true` |
| 官方客户端入房 | 能使用启动接口返回的 `AppId`、`RoomId` 和 `TaskId` |
| 正常主人语音 | RTS `subv` 有正确名称和分数，最终为 `owner_verified` |
| 未匹配语音 | 身份为 `guest`，不开放私有能力 |
| 低分语音 | 身份为 `guest` |
| `stat` 状态回调 | 只表示功能状态，不授予主人身份 |
| 停止后旧回调 | `RTC_SESSION_NOT_ACTIVE` |
| TTL 后旧回调 | `RTC_SESSION_NOT_ACTIVE` |
| 重启后旧回调 | `RTC_SESSION_NOT_ACTIVE` |
| SAUC ASR 回调 | 不能进入 RTC 声纹身份桥 |
| 缺少 HMAC | `401 VOICEPRINT_BRIDGE_UNAUTHORIZED` |

## 13. 常见问题

### `VOICEPRINT_NOT_CONFIGURED`

检查：

- `VOICEPRINT_PROVIDER` 是否为 `volcengine-rtc`；
- `VOICEPRINT_RTC_OWNER_NAME` 是否非空；
- `VOICEPRINT_RTC_SCORE_THRESHOLD` 是否在 `1` 到 `100`；
- `VOICEPRINT_RTC_BRIDGE_SECRET` 是否非空；
- 后端进程是否重启并重新读取 `.env`。

### RTC OpenAPI 尚未完成服务端配置

检查：

- `VOICEPRINT_RTC_ACCESS_KEY_ID`；
- `VOICEPRINT_RTC_SECRET_ACCESS_KEY`；
- `VOICEPRINT_RTC_APP_ID`；
- `VOICEPRINT_RTC_REGION`；
- `VOICEPRINT_RTC_API_VERSION`；
- 云端账号是否有 RTC OpenAPI 权限。

### `RTC_SCENE_NOT_CONFIGURED` 或场景无声纹

检查 `backend/config/voiceprint-rtc-scene.json` 是否存在，并确认 `AgentConfig.VoicePrint.IdList` 中已经写入 `RegisterVoicePrint` 返回的 ID。不要直接把示例字符串当成真实 ID。

### 回调能解析但没有 `owner_verified`

按顺序检查：

1. `voiceprintName` 是否与 `VOICEPRINT_RTC_OWNER_NAME` 完全一致；
2. `voiceprintScore` 是否达到阈值；
3. Worker 使用的 `--task-id` 是否是本次 `StartVoiceChat` 返回的真实任务号；
4. 回调是否来自本次官方客户端/SDK 实测；
5. 当前任务是否已经停止或过期；
6. 后端是否在 Worker 提交前重启过。

### `RTC_SESSION_NOT_ACTIVE`

这通常表示：

- Worker 使用了旧 TaskId；
- 已调用 `StopVoiceChat`；
- 本地网关重启过；
- `VOICEPRINT_RTC_SESSION_TTL_SECONDS` 已过期；
- 实时验收脚本误用了历史回调文件。

### `401 VOICEPRINT_BRIDGE_UNAUTHORIZED`

检查 Worker 和后端是否读取同一个 `.env`、系统时间是否准确、桥接密钥是否被改动。不要把桥接密钥放入命令行参数。

### 只能看到 ASR 文本，不能完成声纹认证

这是预期的链路隔离结果。SAUC ASR 只能提供转写，不提供本项目所需的 RTC 声纹身份事件。需要让官方 RTC 客户端/SDK 加入 VoiceChat 任务，并把已确认的 RTC 回调交给 provider mapper。

## 14. 建议的验收时机

在以下条件满足后做最终官方实测最合适：

1. WAV 已成功注册，场景文件已写入真实 `VoicePrintId`；
2. `--mode config` 通过；
3. `--mode offline --expect-match` 通过；
4. 官方客户端/SDK 的入房和回调输出已经准备好；
5. 后端网关和 Worker 使用同一份服务端 `.env`；
6. 能够安全地进行一次真实云端会话，并接受可能产生的云端费用或配额消耗。

在这些条件满足前，不要把“本地测试通过”表述为“声纹最终认证完成”。

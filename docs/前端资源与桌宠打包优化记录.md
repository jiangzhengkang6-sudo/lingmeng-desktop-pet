# 前端资源与桌宠打包优化记录（2026-09-13）

## 前端按需加载

- 新增 `src/identity/officialRtcRuntime.ts`，将 `@volcengine/rtc` 改为运行时 `import()` 动态加载。
- `OfficialRtcVoiceprintClient` 不再静态导入官方 RTC SDK；只有用户点击“官方 SDK 加入并发麦克风”时才加载 RTC chunk。
- `PetCanvas` 不再启动时预加载 manifest 中的全部 SpriteSheet，只加载当前动作需要的图片；切换动作时按需加载。
- Vite 配置 `assetsInlineLimit=0`，大 SpriteSheet 保持独立 PNG，不内联到 JS。
- 主入口 JS 从优化前约 2.30 MB 降至约 0.20 MB（gzip 约 66 KB）。
- 官方 RTC SDK 独立异步 chunk：`index.esm.min-*.js`，约 2.09 MB（gzip 约 639 KB），不阻塞首屏。
- 17 张角色 SpriteSheet 仍作为独立资源输出；这是动画必需资源，不应再按 JS chunk 警告处理。

它解决什么问题？

市面上的 AI 陪伴产品，要么是个"聊天框套壳"，要么把你的每句话都送上云端。

传统 AI 桌宠 / 助手的痛点

  • 只会聊天，动作是贴图轮播，毫无"生命感"
  • 模型可以执行任意命令，安全全靠运气
  • 对话记录、API Key、生物特征全托管在云端
  • 绑定单一厂商，换模型 = 重写一遍
  • 黑盒运行，出错不知道卡在哪一环

本项目的设计答案

  • 模型输出直接驱动 8+ 种动作与口型同步，回复即表演
  • 模型没有任何执行权，操作必过白名单+审批+审计
  • 本地优先：配置、记忆、审计、人脸特征全部留在本机
  • OpenAI 兼容协议适配，换模型只改环境变量
  • 全链路阶段状态 + trace_id + 本地调试历史，出错可定位

六个值得一提的亮点

🛡️

模型无执行权的四层安全

前端只调网关 → Pydantic 校验 → 白名单与人工审批（中风险操作 10 分钟内须确认）→ SQLite 审计留痕。即使主人验证通过，也绕不过审批。

🎭

结构化输出驱动"表演"

大模型按 JSON Schema 严格输出情绪、动作、口型，一个响应同时驱动对话 UI、Godot 动作状态机与口型能量同步——回答即演出。

🧠

用户确认制记忆

模型最多"提议"3 条记忆候选，永不自动保存；主人确认后才生效，敏感信息（密钥/卡号/证件号）入库前直接拦截。

📸

完全离线的人脸身份

OpenCV YuNet 检测 + SFace 128 维身份嵌入，本地余弦比对（阈值 0.45）识别主人，无云端、无上传；身份抽象为适配器协议，声纹→人脸、关键点→SFace 两次迁移权限体系零改动。

🎙️

三语语音全链路

唤醒词门控 → VAD 断句 → 流式 ASR → 意图规划 → TTS 合成 → 口型同步，中/日/英实测闭环，明确指令走本地规则 1 秒响应。

🧪

工程化交付

276 个单元测试 + 非破坏性 E2E 验收脚本 + PyInstaller/Tauri 一键 MSI 打包，降级策略保证云端故障时聊天不中断。

核心功能一览

桌宠 Live 演出系统

Godot 4.7 透明窗口渲染，待机/聆听/思考/说话/不悦/害羞等动作状态机，口型随语音能量实时开合，缺资源自动回退占位动画。

受控桌面工具

查时间、开白名单应用、搜授权目录、播放/暂停音乐、设本地提醒——每一项都登记在册、分级风控、执行留痕。

RAG 角色知识库

Milvus 双集合存储角色设定与用户文档，检索片段作为"不可信参考资料"注入并附带来源，知识库故障自动降级不影响聊天。

身份与权限体系

unknown / guest / owner_verified 三态；主人解锁长期记忆与高权限工具，访客只能基础对话，每次升降级均有事件审计。

可观测调试台

ASR / Agent / TTS / 工具各阶段状态实时可视，历史记录本地持久化，重启可查、随时清空。

一键安装交付

PyInstaller 打包 Python 网关 + Tauri 生成 MSI 安装包，升级不覆盖用户配置，卸载不泄露密钥。

## 发现的安装器问题

当前机器上旧版本产品 `{070481D3-7E18-4652-BEC2-24AB4AC8954B}` 的 Windows Installer 注册信息将安装目录锁定为：

`E:\Anime‑style AI Agent Desktop Pet\src-tauri\.tauri-target\release\`

尝试指定 `INSTALLDIR=C:\Program Files\Anime Agent Desktop Pet\` 时，MSI 返回成功但仍沿用旧目录。

尝试静默卸载旧产品返回 1603，日志中的关键错误为：

`Error 1730. You must be an Administrator to remove this application.`

因此，干净 Program Files 安装需要人工通过 UAC 管理员权限卸载旧产品后再安装。

## 需要人工完成的最后验收

1. 在 Windows“应用和功能”中卸载旧的 Anime Agent Desktop Pet（需确认 UAC）。
2. 重新安装新生成的 MSI，确认默认目录为 Program Files 或用户选择目录，而不是 `src-tauri/.tauri-target/release`。
3. 从开始菜单启动应用。
4. 人工观察 WebView UI、Godot 桌宠窗口和动作表现。
5. 联网配置真实 `.env` 后测试 ASR、TTS、真实 Agent、RAG。
6. RTC 声纹仍作为高级功能单独验收。

## 当前结论

应用运行时基本功能和打包产物冒烟验收通过；阻塞“干净安装路径验收”的是本机旧 MSI 的管理员卸载权限，不是当前代码运行错误。

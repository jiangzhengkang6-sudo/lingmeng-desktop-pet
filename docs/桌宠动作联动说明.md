# 桌宠动作联动说明（2026-09-13）

## 实际可用主动作

界面“动作状态”只显示有 SpriteSheet 资源的 7 个动作：

1. `idle`：待机
2. `listening`：聆听
3. `thinking`：思考
4. `speaking`：说话
5. `displeased`：不悦
6. `shy`：害羞
7. `open-app`：打开应用

## 业务映射

- ASR 录音中：`listening`
- ASR 识别中 / Agent 思考：`thinking`
- TTS/Agent 回复播报：`speaking`
- 受控工具开始执行、审批通过、打开应用/文件：`open-app`
- ASR/Agent/工具失败，或用户拒绝审批：`displeased`
- 旧事件 `success/working`：映射到 `open-app`
- 旧事件 `failure/refuse`：映射到 `displeased`
- 旧事件 `sleeping/reminder`：映射到 `idle`
- 识别完成且没有新状态：回到 `idle`

统一前端映射函数位于 `src/pet/petActions.ts`，Godot 控制器使用 `_map_available_action()` 做同样的旧事件兼容。

## Godot 行走过渡

从 `idle` 触发以下行走动作时，会先播放对应非循环、不可打断过渡，再进入循环行走：

- `transition-idle-to-walk-left` → `walk-left`
- `transition-idle-to-walk-right` → `walk-right`
- `transition-idle-to-walk-front-left` → `walk-front-left`
- `transition-idle-to-walk-front-right` → `walk-front-right`

Godot 调试键：

- 数字键 `1–7`：七个主动作
- `F1–F6`：六个方向行走，并自动播放对应过渡

## 行走位移节奏

内置角色的一轮行走共 32 帧、8 FPS：

- 第 `0–2` 帧、第 `29–31` 帧是直立启停/停顿姿态；
- 第 `3–28` 帧才允许 Godot 移动桌面窗口；
- 待机转行走过渡动画期间也不允许位移；
- 迈步阶段会按“位移帧数量 / 总帧数量”补偿速度，使整轮平均速度仍保持 `80 px/s`。

该规则由 `godot/pet_client/scripts/WalkMotionPolicy.gd` 统一处理。资源清单可通过
`movement_frame_indices` 显式声明允许位移的帧；旧清单缺少该字段时，内置 32 帧
行走动作会使用相同的兼容默认值。

## 同步链路

- Canvas 预览：当前 `SpriteManifest` + `PetAction`
- Tauri/Godot 预览：`sync_godot_preview_state` 写入 `preview.json`
- WebSocket：`POST /api/pet/events` → Godot `PetEventBridge`
- 外部资源包：Tauri 同步到 `LOCALAPPDATA/LingMengDesktopPet/godot-resource-package`

# 赤红精灵资源说明

## 当前资源

所有动作资源均为透明背景 PNG。主动作使用 `6 × 6` SpriteSheet，尺寸 `3840 × 3840`，每帧 `640 × 640`，前 32 帧有效，末尾 4 格为空白帧；过渡动作使用 `4 × 4` SpriteSheet，尺寸 `2560 × 2560`，每帧 `640 × 640`，16 帧全部有效。

### 主动作（界面动作状态）

1. `idle`：待机。
2. `listening`：聆听。
3. `thinking`：思考。
4. `speaking`：说话。
5. `displeased`：不悦。
6. `shy`：害羞。
7. `open-app`：打开应用。

### 行走动作（不显示在动作状态列表）

1. `walk-left`
2. `walk-right`
3. `walk-front-left`
4. `walk-front-right`
5. `walk-back-left`
6. `walk-back-right`

### 待机转行走过渡（非循环、不可打断）

1. `transition-idle-to-walk-left`
2. `transition-idle-to-walk-right`
3. `transition-idle-to-walk-front-left`
4. `transition-idle-to-walk-front-right`

从待机触发对应行走动作时，Godot 会先播放 16 帧过渡，再自动进入对应循环行走。

## 资源清单

- `manifest.json` 注册 17 个动作：7 个主动作、6 个行走动作、4 个过渡动作。
- Vue 默认资源与 Godot 资源目录保持同步。
- 应用界面的“动作状态”只显示当前有实际主动作资源的 7 项；没有资源的旧动作（工作中、成功、失败、拒绝、休眠、提醒）不显示。
- 旧事件 ID 仍保持兼容：失败/拒绝映射到 `displeased`，成功/工作中映射到 `open-app`，休眠/提醒映射到 `idle`。

## 坐标与锚点

所有动作统一使用 `bottom-center` 锚点和 640 × 640 帧尺寸，避免动作切换时脚底基线跳动。

## 后续新增动作

新增动作时，应同时更新：

1. `src/types/pet.ts` 的动作类型；
2. `src/characters/CrimsonElfIdleSpriteSheet.ts` 的默认资源注册；
3. `src/engine/ResourcePackage.ts` 的资源包动作白名单；
4. `backend/app/pet_events.py` 与 `godot/pet_client/scripts/PetEventBridge.gd` 的事件白名单；
5. Godot `manifest.json`；
6. 前端/Godot 对应测试和资源说明文档。

不要把非循环过渡动作加入“动作状态”列表。
